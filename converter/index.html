From drawing PDF to 3D model

Open a CAD drawing exported as PDF. 2dto3d finds the pages that show a part, reads the views, holes and notes, and builds a STEP model you can open in any CAD program. It all runs on your own computer.

How it works

The PDF keeps the drawing as real lines, arcs and circles, so sizes are measured from the geometry and the sheet scale, not guessed from a picture.

  1. Open a PDF

    Pick a drawing exported from NX, SolidWorks, Creo, Inventor, Fusion or similar.

  2. Scan every page

    Each page is checked for a part. Pages that cannot be used say why, for example an assembly or a scanned image.

  3. Convert

    Convert one page or all usable pages. Each part is built as a solid with its holes, pockets and steps.

  4. Preview and save

    Turn each part around in 3D, then save it as a STEP file for your CAD program.

What it reads from the drawing

Built for plate-type parts: flat plates, blocks and brackets with holes and pockets, drawn in third-angle projection.

Outline and thickness

The outer boundary of the plan view, with true arcs, and the thickness from the side view lined up next to it.

Holes

Through and blind holes and counterbores, on either face, with each step's depth from the side and section views.

Pockets and cut-outs

Inner boundaries cut through, or to the depth of the pocket floor shown in the side view.

Hole notes

Callouts like 6X #10-24 UNC ↧.50 or 26X Ø.21 THRU set the size and depth of every matching hole.

Scale from the title block

The sheet scale is read from the title block, so there is nothing to type in.

Detail, section and turned views

Details are placed on their parent view, sections cut away what they show as empty, and views drawn at an angle are straightened.

Your drawings stay on your computer

2dto3d is a program you run, not a website you upload to.

  • No upload, no account, no server. It works offline.
  • Working files are kept only while the program is open.
  • You choose where each STEP file is saved.

Good to know

  • The PDF must be a vector export from CAD. Scanned drawings have no lines to read.
  • Assembly drawings are skipped; convert the sheets of the single parts.
  • Threads are built at the drawn hole size, and slanted features are left out.
  • Check every model against the drawing before you use it.

Run from source

With Python 3.11 or newer installed:

git clone https://github.com/NectroGT/2dto3d
cd 2dto3d
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5000. The app only listens on your own computer.

Or from the command line:

python scan.py drawing.pdf
python pdf2step.py drawing.pdf --page 3 -o out/
