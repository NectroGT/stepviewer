# ConnectIQ STP Viewer

| Folder | What it is |
| --- | --- |
| [`site/`](site/) | The viewer: open STEP, IGES and BREP files (and STL, OBJ, 3MF and glTF meshes) in the browser, then measure, cut, estimate weight and compare. Published to GitHub Pages at https://nectrogt.github.io/stepviewer/. |
| [`desktop/`](desktop/) | The same viewer as a Windows program (Electron). Installers are on the [Releases](https://github.com/NectroGT/stepviewer/releases/latest) page. |

The viewer runs entirely in the browser (or in the desktop app); files are never uploaded.
